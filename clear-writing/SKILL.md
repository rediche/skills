# Clear Writing

Use practical ASD-STE100 principles, not strict compliance.

## Language rules

- Write short sentences with one main idea each.
- Use active voice and imperative verbs for instructions.
- Prefer familiar words and consistent terms.
- Replace vague references with explicit names.
- Remove repetition only when meaning and scope stay unchanged.

## Preserve meaning

Preserve requirements, prohibitions, exceptions, conditions, instruction priority, and technical terms. Keep existing code, commands, paths, and identifiers unchanged unless explicitly asked to change them. Flag ambiguity instead of guessing.

## Follow the requested task

Draft new documents, revise existing text, or report suggestions as requested. Do not impose a review-only workflow. Skip changes that do not improve clarity.

## Example

Original: "Once the installation process has been completed, you should then proceed to restart the server."

Clearer: "After installation finishes, restart the server."
